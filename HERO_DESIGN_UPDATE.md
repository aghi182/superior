# Hero Section Design Update

## Perubahan yang Telah Dibuat

### 🎨 **Desain Modern Glassmorphism**
- **Layout Grid**: Menggunakan CSS Grid dengan 2 kolom (kiri dan kanan)
- **Glassmorphism Effect**: Efek kaca buram dengan `backdrop-filter: blur(20px)`
- **Gradient Background**: Background gradient biru-ungu yang modern
- **Responsive Design**: Tampilan yang responsif untuk semua ukuran layar

### 🏗️ **Struktur Layout Baru**

#### **Left Content Block:**
- **Logo Card**: Kartu glassmorphism dengan inisial S dan T
- **Company Name**: Nama perusahaan dengan gradient text
- **Tagline**: Subtitle dari database
- **Action Buttons**: Tombol "Learn More" dan "Contact Us"

#### **Right Content Block:**
- **Large Card**: Kartu besar dengan huruf S besar
- **Company Text**: Teks nama perusahaan dalam huruf besar
- **Hover Effects**: Efek hover yang smooth

### 🎯 **Fitur Desain**

1. **Glassmorphism Cards**
   - Background transparan dengan blur effect
   - Border dengan opacity rendah
   - Box shadow yang halus
   - Hover effects yang smooth

2. **Gradient Text**
   - Nama perusahaan dengan gradient warna
   - "SUPERIOR" dalam warna teal
   - "INDONESIA" dalam warna purple-blue

3. **Interactive Elements**
   - Hover effects pada semua cards
   - Button animations
   - Smooth transitions

4. **Responsive Design**
   - Mobile-first approach
   - Breakpoints untuk tablet dan mobile
   - Grid layout yang adaptif

### 📱 **Responsive Breakpoints**

- **Desktop**: Grid 2 kolom dengan gap 4rem
- **Tablet (768px)**: Grid 1 kolom, text center
- **Mobile (480px)**: Layout vertikal, button full width

### 🔧 **CSS Features**

- **Backdrop Filter**: Efek blur untuk glassmorphism
- **CSS Grid**: Layout yang fleksibel
- **CSS Transitions**: Animasi yang smooth
- **Media Queries**: Responsive design
- **Pseudo Elements**: Efek shimmer pada hover

### 📊 **Konten dari Database**

Semua konten tetap diambil dari database:
- `hero_subtitle` untuk tagline
- `hero_button_text` dan `hero_button_link` untuk tombol
- Fallback values jika data tidak ada

### 🎨 **Color Palette**

- **Primary Gradient**: #667eea → #764ba2
- **Teal Gradient**: #20c997 → #17a2b8
- **Glass Effect**: rgba(255, 255, 255, 0.1)
- **Text Colors**: White dengan opacity variations

### ✨ **Efek Visual**

1. **Parallax Background**: Background image dengan blur effect
2. **Gradient Overlay**: Overlay gradient untuk depth
3. **Glassmorphism**: Efek kaca buram modern
4. **Hover Animations**: Transform dan shadow effects
5. **Shimmer Effect**: Efek cahaya yang bergerak pada hover

Desain ini memberikan tampilan yang modern, profesional, dan menarik sesuai dengan tren desain web terkini!
